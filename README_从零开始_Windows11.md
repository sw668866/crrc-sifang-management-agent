## Windows 本机首次核验：五条命令

完整解压工程包，在 VS Code 使用 **File → Open Folder** 打开最内层含 `app.py` 的文件夹，在 **Terminal → New Terminal** 打开 PowerShell。一次只输入一行，等待它完成再进行下一行。

```powershell
py -3.12 --version
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m unittest discover -s baseline_v2_2 -v
```

上述新测试理应显示 `Ran 82 tests` 且 `OK`、不包含 `skipped=`；原版应显示 `Ran 61 tests` 且 `OK`。两者分别测试**新增智能体应用（其中包含120组随机独立Fraction复核）**和**冻结数学内核**。任何出现 `FAILED`、`ERROR` 或 `skipped=` 的结果不能算通过。安装依赖需要联网，**首次安装耗时取决于网络**。

随后启动：

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

浏览器打开 `http://localhost:8501` 时，先在“计算器模式”标签执行 T0，然后使用 H300、H350 与 Y1700 验证 T1；另展开“高级情景参数”确认原本已允许的七类 T1 动态字段均可受控设置。

## 关键安全原则

- **不要把真实百炼 API Key 发给 ChatGPT、任何聊天对象，或放入 GitHub。** 也不要对包含完整密钥的页面进行公开截图。
- 真实本机密钥放在 `.streamlit/secrets.toml`（无 `.example` 后缀）。该文件**不能上传**。
- 开发端点需使用所开通的阿里云百炼业务空间及地域。北京地区官方兼容端点形如 `https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`。请把 `{WorkspaceId}` 换成本人控制台查到的值，不能直接复制花括号。
- **左侧显示“已读取模型配置”只表示字符串存在，不代表 API 已成功连通。** 必须实际进行至少一个对话与工具调用才能判断。
- **每轮动态情景从冻结T1基准单独开始，不会可靠继承上轮H、售价等参数。** 含“那”“沿用上轮”等指代的计算追问会要求重述；仅给“增加50小时”“降低200元”等相对幅度会要求写成新目标绝对值，以免误算。
- 不修改冻结的 T0/T1 会计模型、成本边界和跨期间规则。X/Y 数据均为教学模拟，不是中车四方财务账目。自然语言防错覆盖常见表达，**不代表所有复杂中文语义都已可靠识别**；重要情景必须核对页面或对话结果中的“全部有效输入”。
